# Contributing to [DEBCF: Dynamic Event Booting & Configuration Framework]

Thank you for your interest in helping improve this Stellaris mod! To maintain a stable mod files environment and clear legal boundaries under our Apache 2.0 license, we require all contributors to use the following workflow.

## Rules for Contribution

### 1. Do Not Push Directly to Main
Direct pushes to the `main` and `test` branches are blocked. You must fork the `test` repository, make your modifications in your fork, and submit a Pull Request (PR).

### 2. Code Contribution Workflow
1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork locally to your machine.
3. Create a new branch for your feature or bugfix (e.g., `git checkout -b fix-civic-bug`).
4. Commit your changes. Ensure your code is clean and properly formatted according to Stellaris modding standards.
5. Push your branch to your GitHub fork.
6. Open a **Pull Request** from your fork back to our `test` branch.

### 3. Legal Agreement
By submitting a Pull Request to this repository, you agree that your contributed code, text, or assets will be licensed under the project's existing **Apache License 2.0**. You retain authorship credit, but give permission for the code to be merged, modified, and distributed as part of this project.
